# Version v0.0.15

This release introduces inline raster image previews for datasets and commit widgets in notebook HTML, making it easier to visually inspect image files directly within the interface. The update enhances the user experience when working with image data, especially for PNG, JPEG, GIF, and WebP formats.

## New Features

- Added support for inline raster image previews (PNG, JPEG, GIF, WebP) in notebook HTML using data URIs, with a 2 MiB size cap. Dataset and commit widgets now display image thumbnails when possible. Includes new helpers, updated HTML/CSS, and tests for integration and static HTML rendering. (1ba6b3) (Eric Ma)
