# Version v0.0.14

This release focuses on improving compatibility with different dependency sets in the web interface, ensuring more robust template rendering.

## New Features

_No new features were added in this release._

## Bug Fixes

- Fixed a bug where template rendering could fail under certain dependency sets (e.g., uvx) by ensuring the request object is passed first to Jinja2Templates.TemplateResponse, as expected by Starlette. This resolves issues where the context dictionary was misinterpreted as the template name, causing a TypeError. (3258bf) (Eric Ma)

## Deprecations

_No deprecations were introduced in this release._
